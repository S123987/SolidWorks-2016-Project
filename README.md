# SolidWorks 2016 Project Archive

A collection of CAD parts, assemblies, mesh models, and neutral-format exports organized from the supplied project folders. The archive includes a roller conveyor model, a Raspberry Pi Zero W board model, and assorted mechanical and character models.

## Projects

### `roller-conveyor/`
- Conveyor assembly in STEP format (`.stp`)
- Five reference images (`.jpg`)

### `solidworks/`
- Native SolidWorks part and assembly files (`.SLDPRT`, `.SLDASM`)
- STL mesh models and a GIF mechanism demo
- Additional supplied `.gx` files
- A nested Poké Ball assembly and its component parts

### `raspberry-pi-zero-w-board/`
- Raspberry Pi Zero W board part (`.SLDPRT`)
- IGS, STEP, and STL exports
- Reference image (`.PNG`)

## Opening the files

Open native `.SLDPRT` and `.SLDASM` files in SolidWorks. STEP, IGS, and STL files are provided for exchange with other CAD and 3D tools. Files are preserved in their supplied formats; compatibility and assembly references can depend on the SolidWorks version and the original file set.
